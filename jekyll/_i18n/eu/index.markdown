# Zer egiten du

TurnoClase-k irakasleei klase batean galderak erantzuteko txandak kudeatzen laguntzen die, ikasleek txanda eskatu
eta banan-banan artatuak izan daitezen.

Txandak automatikoki kudeatzen ditu eta norbait ahaztu edo beste ikasle batzuek irakaslearen arreta
monopolizatzeagatik artatua ez izatea ekiditen du.

Ez dago lerrotik ihes egiterik!

Nola funtzionatzen du:

- Hasteko irakaslearen aplikazioak sortutako gela kodea besterik ez da behar.
- Gela badago, zenbat dauden lerroan aurretik erakusten du.
- Lerroa aurrera joan ahala, bilakaera erakusten du.

TurnoClase bi aplikazio independientetan banatuta dago, bat ikaslearentzat eta beste bat irakaslearentzat.
